# Creator Dashboard Server

This is the backend server application for the Creator Dashboard.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
# For Unix/Linux/Mac
npm run dev

# For Windows
npm run dev:win
```

This will start the development server.

### Build

```bash
npm run build
```

### Start Production Server

```bash
npm run start
```

### Database Migration

```bash
npm run db:push
```

### Deployment

The server can be deployed to Google Cloud Platform:

```bash
npm run deploy:gcp
```
