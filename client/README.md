# Creator Dashboard Client

This is the frontend client application for the Creator Dashboard.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

This will start the development server at http://localhost:5173.

### Build

```bash
npm run build
```

### Deployment

The client can be deployed to Netlify:

```bash
npm run build && netlify deploy --prod
```
